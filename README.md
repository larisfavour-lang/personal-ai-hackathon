# 我的小助手：记得身边人的情况，继续办家庭的事

个人 AI 黑客松作品。面向承担孩子学校、活动和家庭安排的人：把本次资料交给助理，继续一件家庭事项；情况变了，可以更正后重新准备，不必从头解释。

作品提供手机优先的对话页、资料库、两个轻量演示视图和 Chrome 浏览器插件。送礼与商店代填是独立的模拟执行证明，不把家庭活动强行接成购物。

## 本地运行

需要 Python 3.10+ 和可用的 OpenAI 兼容模型接口；本轮实际测试环境是 macOS／Python 3.11。以下为 macOS／Linux 的守护启动，使用 `fork`，不支持 Windows 原样运行。Windows 先按[运行指南](<docs/run-standalone.md>)使用前台入口，跨系统干净安装尚未验证。

```bash
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
PA_MODEL_BASE_URL="https://你的模型接口/v1" \
PA_MODEL_NAME="你的模型名" \
PA_MODEL_API_KEY="你的密钥" \
python start_server.py 8000
```

已有本机代理时，可直接执行 `python start_server.py 8000`。默认接口为 `http://127.0.0.1:10100/v1`，默认模型标签为 `step/step-5-preview`；这个本机代理不随源码分发。接口、模型和密钥由运行者提供，不能在别的电脑上照抄默认代理就假定模型可用。

电脑打开 `http://127.0.0.1:8000`。启动程序会另外打印当前局域网地址；手机与电脑在可互访的同一局域网时，扫码首页「⋯ → 演示设置 → 手机访问 → 在手机上打开」的当前二维码即可。电脑必须保持开机与服务运行。手机的 `127.0.0.1` 指手机自己，不能用它访问电脑。

服务默认监听 `0.0.0.0`；仅本机使用时设 `PA_BIND=127.0.0.1`。局域网访问不是公网评委体验链接，也没有公开注册／登录系统。局域网 HTTP 下的相机、麦克风和主屏安装能力由浏览器决定。

更多启动说明见[运行指南](<docs/run-standalone.md>)。普通用户使用已启动的演示服务，无需配置模型或切换他人身份。演示设置中的模型配置仅供运行者维护；密钥保存在本地运行库，不应随源码分享。

## 从一件家庭事项开始

1. 说「周末三家一起带孩子出去玩，我出100以内」，打开回复里的同一事项。100 元是本人出资上限，不是活动总预算或付款承诺。
2. 查看当前知道的家庭、候选参与者、孩子信息和待确认条件。演示 A／B／C 是三个身份，B 小周与 C 小林同户，实际是两个家庭；第三家未知时保留缺口，不把配偶凑成第三家。
3. 按当前条件排候选方案。只有真正参与者接受同一个版本，才能记为已约定；模型代表审阅与本人点击确认分开记录，未回应仍是待确认。
4. 改自己的时间、出资上限等条件后，重新准备新版本。旧接受失效，完成历史保留。失败时查看原因并重试，不把失败或安全拒绝当作协商成功。

限定来宾与资料用于家庭活动已在 t27 独立范围内通过。发起人从事项「邀请另一个家庭参与 → 生成单次邀请」给出单用链接；接收者在独立浏览器接受邀请并自称，只补自己的条件和孩子名单；发起人「认可自称家庭」后，依所有当前条件重排出新的可表态版本，再由来宾本人对这一版回应。条件变化后不能直接接受旧版。代表审阅只是建议，来宾本人接受才计数；链接不证明实名，不映射 B／C、不继承其资料。名单数不等于出席，一个来宾不自动凑齐三家。清空 cookie 后仍存在旧默认 A 演示入口，不能当生产认证。

资料保存后选「用于家庭活动」，默认零选字段，先关联本人私有来源，再选已核对的短字段原值并确认公开本方条件。正文和图片不自动共享；更正或撤回后旧接受失效，重新选择、公开、重排，并以当前服务器出处证明新值实际采用。步骤见[交付说明](<docs/delivery/DELIVERY.md>)与[安卓清单](<docs/delivery/ANDROID-CHECKLIST.md>)。

## 录入、核对与再次使用

从「☰ → 资料库 → 添加资料」进入，同一个「记什么」正文框可以先写字，不必先拍照或选人。

- 默认「加一张图」：图片出现后自动识别整图，文字追加在原正文末尾，中间换行；本人已写的内容保留。无需再点一次「读出文字」。核对错字、对象和发生日期后保存，再打开记录检查正文、来源与配图。
- 首次就限制识别范围：在选图前点「先裁剪再识别」，再选图并确认范围。只有选定范围送识别；取消裁剪不调用识别。不能默认加图后再声称整图未上传。
- 首次只存图片：在选图前点「只作配图」，再选图；不调用识别。默认识别后改点缩略图下的「只作配图，不识别」，只改变采用方式，不撤销此前已经发生的整图识别。
- 识别失败会说明原因，保留图片与本人正文；可以编辑、重试或稍后继续。模型返回空白不算识别成功。取消草稿不新增记录。

保存资料本身不取得对外分享、替他人承诺或执行权限。可用于某件事的资料需由本人明确选择，再按对象、用途和授权筛选；仅保存、未被采用的内容不能写成「本次依据」。资料发生日期与家庭活动日期分别核对。

学习记录与周末安排视图使用本作品内的测试来源，展示授权后的近况与建议、更正及撤回；未接通真实学校软件、微信或手表。

## Chrome 插件：换页面少重说

电脑 Chrome 打开 `chrome://extensions`，启用开发者模式，加载[插件目录](<extensions/context-bridge>)。插件名为「随身助手」。

需要演示代填时，另开终端启动内置模拟商店：

```bash
python -m http.server 9000 --bind 127.0.0.1 \
  --directory extensions/context-bridge/fixtures/mock-shop
```

1. 在主应用「⋯ → 演示设置 → 浏览器插件」取得配对码，在插件中连接本人服务。
2. 选择本人的购物事项，查看本次需求、来源、待确认项与可复制的需求说明；换页面继续同一件事，纠正后重新取当前参数。
3. 在支持的模拟商店页面预览参数，由本人确认后代填；插件实际读回页面值，应用同一事项可查看回执。
4. 回执只说明页面被填及复核结果；插件不提交订单、不付款。未适配网页走复制需求、本人手动继续，不能声称已代填真实电商。

正式插件的固定站点权限为本机 8000／8097／9000／8098；不是任意手机浏览器可安装的扩展。家庭活动计划不进入只支持购物用途的参数包。重置演示资料会清除插件设备与配对状态，已经连接的设备需重配；日常试用不要重置。

## 安全与数据说明

模型负责抽取、提案、审阅、读图和建议，程序检查对象、授权、预算依据、品类、规格和同版本接受。过期、跨事项或未经确认的方案不能用于执行；错误确认不应留下接受、约定或订单痕迹。

演示人物、关系和商品是虚构 seed，购买、支付和物流均为 `simulated`，不发生真实交易。文本及选定的识别图像会发送给运行者配置的模型服务；附件查看权限与用于模型处理的授权分别检查。请只用无敏感内容的虚构资料演示。

## 语音与其他边界

服务端 ASR 已实测不可用：带前缀的 `step/stepaudio-2.5-asr` 返回 404 `model_invalid`，裸名返回 502 `Provider unreachable`；标准音频转写／语音端点不存在，音频 chat 模型可达但未产出转写。26 次请求与对照说明见[语音核查摘要](<docs/delivery/verification-summary.md>)。

「说一段」使用浏览器 SpeechRecognition，识别不经本作品服务端；浏览器可能使用自己的识别服务，受设备、权限与安全上下文限制。自动化只验接线，真实麦克风仍待实测。不可用时直接打字，或用输入法语音转文字后粘贴；这不算内置 ASR 完成。

Step 使用证据只说明配置标签和可核对的实际调用范围，不给未经比赛口径统计的百分比，也不宣称已取得直接上游身份捕获或硬件加分资格。未实现真实电商、群消息发送、外部 Agent 接力、语义检索及公开多用户认证。
