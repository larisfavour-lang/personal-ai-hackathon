## 0. 定位与当前形态

产品定位是个人 AI 的能力底座：支撑跨应用记忆复用和跨用户协商办事，不由当前前端形态定义。人物关系、来源与时效、应用读取范围、个人代表权限和事项版本由共同底座持有；记忆持久存在，各应用提供适合自己任务的界面。

同一个底座有两种未来形态：一种是作为现有 Agent 调用的能力，通过适配接口读取／修正有效人物信息、发起协商、查询执行结果；另一种是承载独立的 PA，有自己的交互入口、事项管理和在明确授权下的事件续办。两种形态共用核心状态与业务规则，不以前端技术决定产品方向。

当前只交付其中一种形态的一个切片：独立 PA 形态下的手机优先 Web 演示，桌面 Chrome 插件作为电脑端的执行手。本文所述的本地 Web／PWA 演示是这个切片的形态，不是产品定位本身；其它形态没有实现，也没有被任何外部 Agent 或平台接入。

## 4. 手机上按新版流程使用

电脑提供当前二维码，手机和电脑连接可互访的同一局域网；电脑保持开机与服务运行。局域网地址随网络变化，不复用历史固定 IP，也不是公网评委入口。普通使用无需配模型、清空资料或切换为他人。

### 资料录入

1. 「☰ → 资料库 → 添加资料」，先在「记什么」正文框输入文字。
2. 一级选项点「图片识别」选图／拍照：缩略图出现、图进草稿，**此时图还没有送出去**，弹层内会问你要拿它做什么。
3. 选「识别图里的文字，进正文框」之后才把图送去做识别；文字追加在原正文末尾、中间换行，原输入保留；直接核对这个正文框中的错字、对象和资料发生日期。
4. 选「只把图存进资料库，不识别」则一次模型都不调用，图只作为配图随记录保存；弹层内会明确反馈「没有识别图里的字」。
5. 「语音输入」走浏览器自带语音识别，说的话直接进正文，可以改完再保存；不支持或拒麦克风时如实说明。
6. 保存后再次打开，检查最终正文、来源、日期与配图；发生日期与活动日期是不同概念。
7. 识别失败在弹层内显示原因，图片与本人原文保留，允许编辑／重试。结果空白不能算识别成功。

「先裁剪再识别」是次级选项：只有框选范围送识别，取消裁剪不调用识别。已经送出去过的图再改范围，不能声称原图从未送出；这一步的说明写在图片区下方，不依赖被弹层盖住的全局状态行。

保存本身不自动挂到事项、不授权分享或替别人承诺。购物资料关联已有证据；家庭活动关联与更正再次采用已有 t27 限定独立输入回读；采用本人选定短字段，关联与公开分两步，当前服务器出处证明新值实际采用。不能只做跳转而宣称资料已用于方案。
